# Deposition Learning Track

Progressive skill development from chamber maintenance through independent thin film fabrication. Check off items as you complete them.

---

# Level 1: Sputtering Chamber Operations

## Fundamentals

- [ ] Read sputtering system manual
- [ ] Understand DC vs RF sputtering — when to use each
- [ ] Learn what base pressure means and why 3×10⁻⁹ Torr matters (film purity)
- [ ] Understand sputter gas (Ar) pressure effects on film quality
- [ ] Learn target materials: Nb, Ta, Cu-Sn alloy

## Chamber Maintenance — Supervised

- [ ] Open the chamber (venting procedure)
- [ ] Clean chamber interior (remove flaking, wipe shields)
- [ ] Change a sputtering target (remove old, mount new, check bonding)
- [ ] Remove and replace chamber lining/shields
- [ ] Seal the chamber (check O-rings, hand-tighten bolts in star pattern)
- [ ] Pump down sequence: rough pump → turbo pump → ion pump
- [ ] Verify base pressure reaches 3×10⁻⁹ Torr (read ion gauge)
- [ ] Bake-out procedure if base pressure is too high

## Chamber Maintenance — Independent

- [ ] Full maintenance cycle without guidance (open → clean → seal → pump)
- [ ] Diagnose common problems (leak, outgassing, target arcing)
- [ ] Log maintenance in lab notebook with date, target change, pressure achieved

# Level 2: DC Sputtering — Nb Films

## Fundamentals

- [ ] Understand the plasma ignition process
- [ ] Learn power, pressure, and distance effects on deposition rate
- [ ] Understand substrate preparation (cleaning protocol from Santosh)
- [ ] Learn masking technique for thickness measurement step

## Supervised Practice

- [ ] Clean substrates (solvent cleaning sequence: acetone → IPA → DI water)
- [ ] Load substrates into chamber with proper fixturing
- [ ] Set sputtering parameters (power, Ar pressure, target-substrate distance)
- [ ] Pre-sputter target to remove oxide layer (shutter closed)
- [ ] Deposit Nb film — monitor power, pressure, time
- [ ] Unload samples without contamination
- [ ] Record all parameters in lab notebook

## First Experiment: 300nm Nb on Sapphire

- [ ] Prepare sapphire substrates (clean + mask for step height)
- [ ] Calculate required deposition time for 300nm target thickness
- [ ] Deposit film
- [ ] Measure thickness — verify within 10% of target
- [ ] Hand off to Kegan for SEM, Tc, XRD characterization
- [ ] Review characterization results — correlate with your deposition conditions

## Independent

- [ ] Run a full deposition start-to-finish without guidance
- [ ] Adjust parameters to hit a target thickness within ±10%
- [ ] Troubleshoot: target poisoning, arcing, non-uniform films
- [ ] Maintain consistent deposition rate across multiple runs

# Level 3: DC Sputtering — Nb on Cu

## New Concepts

- [ ] Understand Cu substrate differences (thermal conductivity, surface prep, oxidation)
- [ ] Learn why Cu-Nb adhesion matters and how surface prep affects it
- [ ] Understand thermal expansion mismatch (Cu vs Nb) and stress effects

## Practice

- [ ] Prepare Cu substrates (mechanical polish + chemical clean)
- [ ] Deposit 300nm Nb on Cu using validated parameters from sapphire
- [ ] Compare film adhesion (tape test) with sapphire samples
- [ ] Hand off to Kegan — compare Tc and morphology with sapphire baseline
- [ ] Document any parameter changes needed for Cu vs sapphire

---

# Level 4: Multilayer Deposition

## Fundamentals

- [ ] Understand the Ta diffusion barrier role (prevents Cu-Nb interdiffusion)
- [ ] Learn the bronze route: Cu-Sn layer provides Sn source for Nb₃Sn formation
- [ ] Understand the full layer stack: Cu substrate → Ta → CuSn → Nb
- [ ] Learn target switching sequence and contamination prevention

## Practice

- [ ] Deposit Ta barrier layer on Cu (set power, time for target thickness)
- [ ] Deposit CuSn layer (switch to CuSn target)
- [ ] Deposit Nb top layer (switch to Nb target)
- [ ] Complete full multilayer stack on a flat coupon sample
- [ ] Review cross-section SEM with Kegan to verify layer structure

---

# Level 5: Thermal Evaporation

## Fundamentals

- [ ] Understand thermal evaporation vs sputtering — advantages for Sn deposition
- [ ] Learn why thermal evap produces low-impurity films (key advantage of our method)
- [ ] Understand boat/crucible loading and evaporation rate control

## Practice

- [ ] Load Sn source material into evaporation boat
- [ ] Set up substrate holder and shutter
- [ ] Pump chamber to required base pressure
- [ ] Evaporate Sn at controlled rate — monitor with crystal thickness monitor
- [ ] Deposit Sn layer as part of multilayer stack

---

# Level 6: Heat Treatment

## Fundamentals

- [ ] Understand Nb₃Sn formation via Cu-Sn-Nb ternary reaction (600-700°C)
- [ ] Learn why our temperature range enables Cu substrates (vs 1100°C for Sn vapor)
- [ ] Understand atmosphere requirements (vacuum or inert gas)
- [ ] Learn about the Sn-reservoir design and why it enables post-reaction optimization

## Practice

- [ ] Load coated sample into tube furnace
- [ ] Program temperature ramp, hold, and cool-down profile
- [ ] Monitor temperature with thermocouple
- [ ] Unload sample after cool-down — inspect visually for delamination or discoloration
- [ ] Hand off to Kegan for full characterization
