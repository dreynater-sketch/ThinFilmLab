# Characterization Learning Track

Progressive skill development from observation through independence. Check off items as you complete them. Each section builds on the previous one.

---

# Level 1: SEM / EDS / FIB

## Fundamentals

- [ ] Read SEM operating manual for our instrument
- [ ] Understand electron-sample interactions (SE vs BSE imaging)
- [ ] Learn vacuum requirements and sample loading procedure
- [ ] Observe a session with an experienced operator

## Supervised Practice

- [ ] Load and unload samples independently
- [ ] Set accelerating voltage and working distance for thin film imaging
- [ ] Capture micrographs at multiple magnifications (1k, 5k, 10k, 50k)
- [ ] Identify grain boundaries and surface morphology in Nb films
- [ ] Perform EDS point analysis — identify Nb, Cu, Sn, Ta peaks
- [ ] Perform EDS area mapping — generate composition maps
- [ ] Cross-section imaging with FIB — observe layer stack (Ta/CuSn/Nb)

## Independent

- [ ] Image a new sample start-to-finish without guidance
- [ ] Measure grain size from SEM micrographs (ImageJ or equivalent)
- [ ] Quantify EDS composition and compare with RBS results
- [ ] Prepare a standard results summary (micrographs + EDS table + grain size)
- [ ] Troubleshoot common issues (charging, drift, contamination)

---

# Level 2: SQUID Magnetometry (Critical Temperature)

## Fundamentals

- [ ] Read MPMS SQUID operating manual
- [ ] Understand DC magnetization measurement principle
- [ ] Learn what Tc, ΔTc, and onset vs midpoint Tc mean physically
- [ ] Understand why sharp transitions (ΔTc < 1K) indicate homogeneous Nb₃Sn

## Supervised Practice

- [ ] Mount thin film sample on SQUID sample holder
- [ ] Set up zero-field-cooled (ZFC) and field-cooled (FC) measurement sequence
- [ ] Run M vs T measurement from 4K to 20K (for Nb₃Sn) or 4K to 12K (for Nb)
- [ ] Process raw data — extract Tc onset, Tc midpoint, and ΔTc
- [ ] Compare results: Nb on sapphire (expect ~9.2K) vs Nb₃Sn (expect ~16-18K)

## Independent

- [ ] Run a full Tc measurement start-to-finish
- [ ] Identify artifacts (trapped flux, paramagnetic background, substrate signal)
- [ ] Plot publication-quality M(T) curves with labeled transitions
- [ ] Compare measured Tc with literature values and flag anomalies
- [ ] Build a standard Tc measurement protocol document

---

# Level 3: XRD (Phase Identification)

## Fundamentals

- [ ] Understand Bragg's law and diffraction geometry
- [ ] Learn which peaks correspond to Nb, Nb₃Sn (A15), Cu, Ta, oxide phases
- [ ] Understand the difference between θ-2θ scan and grazing incidence XRD for thin films

## Supervised Practice

- [ ] Mount thin film sample and align in diffractometer
- [ ] Run a θ-2θ scan over appropriate 2θ range (20-80°)
- [ ] Index peaks using PDF database — confirm Nb₃Sn A15 phase
- [ ] Identify secondary phases (Nb₆Sn₅, NbSn₂, Nb oxide)
- [ ] Estimate crystallite size from peak broadening (Scherrer equation)

## Independent

- [ ] Run and analyze XRD for a new sample without guidance
- [ ] Distinguish between A15 Nb₃Sn and competing phases confidently
- [ ] Relate phase purity to processing conditions (temperature, Sn content)
- [ ] Prepare XRD summary with indexed pattern and phase assignment

---

# Level 4: PPMS RF (Quality Factor)

## Fundamentals

- [ ] Read about cavity quality factor Q and its physical meaning
- [ ] Understand surface resistance Rs and its relationship to Q
- [ ] Learn the difference between the mushroom cavity (SLAC) and our PPMS-compatible cylindrical cavity
- [ ] Understand why Q measurements in magnetic field (up to 9T) matter for axion detection

## Supervised Practice

- [ ] Load sample into PPMS RF cavity fixture
- [ ] Connect VNA and calibrate for S21 transmission measurement
- [ ] Measure resonant frequency and 3dB bandwidth — calculate Q
- [ ] Run Q vs temperature sweep
- [ ] Run Q vs magnetic field sweep (0 to 9T)

## Independent

- [ ] Full RF measurement cycle: mount → cool → measure → extract Q
- [ ] Analyze Q(T) and Q(B) data — identify trends and anomalies
- [ ] Compare Q values across different film recipes
- [ ] Troubleshoot coupling issues, background resonances
- [ ] Produce standard RF results package (Q vs T plot, Q vs B plot, summary table)

---

# Level 5: Thickness Measurement

## Fundamentals

- [ ] Understand profilometry principle (stylus vs optical)
- [ ] Learn what step height measurements tell us about deposition rate

## Practice

- [ ] Measure film thickness on a masked sample
- [ ] Calculate deposition rate (nm/min) from thickness and deposition time
- [ ] Cross-check with SEM cross-section measurement
- [ ] Document standard operating procedure

# Milestone Checkpoints

- [ ] **Checkpoint 1**: Can independently characterize an Nb/Sapphire film (SEM + Tc + XRD + thickness)
- [ ] **Checkpoint 2**: Can independently characterize an Nb/Cu film and compare with sapphire baseline
- [ ] **Checkpoint 3**: Can run full RF characterization on a cavity sample in PPMS
- [ ] **Checkpoint 4**: Can train a new student on SEM and SQUID measurements
