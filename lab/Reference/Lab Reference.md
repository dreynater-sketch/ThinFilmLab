# Training Sequence

New lab members follow this order:

1. **Sputtering Chamber Maintenance** — Open, clean, change target, replace lining, seal, pump down to 3E-9 Torr
2. **Thin Film Fabrication** — Sample prep (Santosh), DC/RF sputtering, thermal evaporation
3. **Characterization** — Thickness measurement (Santosh), SEM/EDS/FIB, SQUID Tc (Kegan), PPMS RF (Kegan)

# Process Notes

**Sputtering Chamber Maintenance Checklist:**

- Open chamber
- Clean chamber interior
- Change target (if needed)
- Remove/replace lining
- Seal chamber
- Pump down to 3×10⁻⁹ Torr (verify with ion gauge)

**Hot Bronze Recipe 1 — Layer Stack:**

4. Ta diffusion barrier on Cu cavity
5. Cu-Sn bronze layer (thermal evaporation)
6. Nb layer + in-situ heat treatment (600-700°C)
7. Nb₃Sn forms via Cu-Sn-Nb ternary reaction
