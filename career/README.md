# Career

Personal career material. **Not research data and not agent-authored.** Agents (Cursor, Claude Code) should not lint, cross-reference into `wiki/`, auto-expand, or touch this folder unless explicitly asked.

## Contents

- [[linkedin]] — headline options, About section, Featured/Skills/Recommendations checklist
- [[resume-cv]] — CV / resume drafts (placeholder)
- [[applications/]] — one file per job application, dated
- [[interviews/]] — interview notes, panel questions, follow-ups (placeholder)
- [[network]] — contacts, intros to request, warm leads (placeholder)

## Conventions

- Application filenames: `YYYY-MM-DD Company - Role.md`
- Keep form answers verbatim (exactly what was pasted into the form)
- Flag any text that was AI-drafted with `> [!note] AI-drafted — review before reuse`
